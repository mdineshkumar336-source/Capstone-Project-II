Full Analytics & Insights System

Project Overview

This project is an end-to-end data analytics project using customer and order data.

Tools Used :

1. Python,
2. Pandas,
3. NumPy,
4. SQL,
5. Excel,
6. Power BI.


Project Modules :

1. Data Audit & Cleaning,
2. Python & NumPy Analysis,
3. Pandas & EDA,
4. Statistics,
5. Data Visualization,
6. Excel Reporting,
7. SQL Analysis,
8. Power BI Dashboard,
9. Customer Segmentation,
10. KPI Reporting,
11. Business Insights Report.


Key Work :

1. Cleaned missing and duplicate data,
2. Standardized text values,
3. Checked unmatched CustomerIDs,
4. Performed statistical and exploratory analysis,
5. Created visualizations and KPIs,
6. Built customer segments using KMeans,
7. Created an interactive Power BI dashboard,
8. Prepared business insights and recommendations.


Files :

1. data/ – CSV datasets,
2. python/ – Python code,
3. sql/ – SQL queries,
4. excel/ – Excel reports,
5. powerbi/ – Power BI dashboard,
6. report/ – Business Insights Report,
7. visuals/ – Charts.
